The Purpose of a README File

A README file is the first thing a user sees when visiting a repository. Its purpose is to explain what the project does, how to install it, and how others can contribute to it effectively.

What is a Git Branch?

A branch in Git is a version of your repository that diverges from the main project. It allows you to develop features or fix bugs in isolation without affecting the stable "main" code.
